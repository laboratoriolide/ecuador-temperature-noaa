# Data Dictionary

## Raw data

### `data/raw/weather/`

Downloaded from NOAA Physical Sciences Laboratory (PSL) CPC Global Temperature and Precipitation datasets.

| Directory   | Variable          | Units | Source URL                                                      |
|-------------|-------------------|-------|-----------------------------------------------------------------|
| `tempmax/`  | Daily maximum temperature | °C | `https://downloads.psl.noaa.gov/Datasets/cpc_global_temp/`     |
| `tempmin/`  | Daily minimum temperature | °C | `https://downloads.psl.noaa.gov/Datasets/cpc_global_temp/`     |
| `precip/`   | Daily precipitation       | mm  | `https://downloads.psl.noaa.gov/Datasets/cpc_global_precip/`   |

- **File format:** NetCDF (`.nc`)
- **File naming:** `{variable}.{year}.nc` (e.g., `tmax.2023.nc`)
- **Years covered:** 2008–2024
- **Spatial coverage:** Global raster grid (~0.5° resolution)
- **Temporal resolution:** Daily

### `data/raw/shapefiles/`

Downloaded from INEC (Instituto Nacional de Estadística y Censos) Geoportal.

| Directory                  | Contents                                       |
|----------------------------|------------------------------------------------|
| `ecuador_shapefiles/SHP/`  | Canton, parish, and province boundary polygons |
| `ecuador_dpa_metadata/`    | DPA (División Política Administrativa) codebook (PDF + XLS) |

Key shapefiles:
- `nxcantones.*` — 221 canton boundaries (used in processing)
- `nxparroquias.*` — Parish boundaries
- `nxprovincias.*` — Province boundaries

Key attributes in `nxcantones`:
- `DPA_CANTON` — 4-digit canton code (province code + canton code within province)
- `DPA_PROVIN` — 2-digit province code

## Processed data

### `data/processed/`

Output of `code/03_process_canton_weather.R`. One CSV per weather variable.

| File                   | Variable              |
|------------------------|-----------------------|
| `max_temperature.csv`  | Daily maximum temperature (°C) |
| `min_temperature.csv`  | Daily minimum temperature (°C) |
| `precipitation.csv`    | Daily precipitation (mm) |

**Schema (all three files share the same structure):**

| Column      | Type    | Description                                          |
|-------------|---------|------------------------------------------------------|
| `canton_id` | string  | 4-digit DPA canton code (e.g., `"0101"`)             |
| `date`      | date    | Observation date (`YYYY-MM-DD`)                      |
| `value`     | numeric | Weighted mean of raster cells within canton boundary |
| `year`      | integer | Calendar year (derived from `date`)                  |

- **Rows:** ~1.38 million per file (223 cantons × ~6,205 days)
- **Date range:** 2008-01-01 to 2024-12-31
- **Extraction method:** Area-weighted mean of raster cells intersecting each canton polygon
